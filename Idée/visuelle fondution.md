Couleurs Premium (Fiches Détaillées)1. Primary RoseHEX : #B76E79RGB : rgb(183, 110, 121)HSL : hsl(351°, 33%, 57%)Usage : Identité visuelle majeure, CTA principaux, liens survolés, icônes actives.Accessibilité : Conforme WCAG AA pour le texte grand format sur fond blanc/crème. À associer au texte Blanc (#FFFFFF) lorsqu'utilisé en fond de bouton.2. Primary DarkHEX : #1E1E24RGB : rgb(30, 30, 36)HSL : hsl(240°, 9%, 13%)Usage : Header principal, footer, boutons CTA de conversion directe, typographie contrastée.Accessibilité : Conforme WCAG AAA sur fond clair (Contraste supérieur à 15:1).3. Soft PinkHEX : #F7E7E6RGB : rgb(247, 231, 230)HSL : hsl(4°, 49%, 94%)Usage : Fonds de bannières, arrière-plans de cartes produit au survol, puces d'état.Accessibilité : Couleur de surface. Nécessite une typographie sombre (#1E1E24 ou #2C2C2C) pour un contraste optimal (WCAG AAA).4. Warm BeigeHEX : #E8DFD8RGB : rgb(232, 223, 216)HSL : hsl(26°, 26%, 88%)Usage : Bordures de conteneurs, lignes de séparation (dividers), arrière-plans secondaires.Accessibilité : Destiné uniquement aux éléments structurels non-textuels (dépassera le seuil de 3:1 pour l'UI).5. Cream WhiteHEX : #FAF7F5RGB : rgb(250, 247, 245)HSL : hsl(24°, 33%, 97%)Usage : Fond global de l'application. Offre une alternative plus chaleureuse au blanc pur.Accessibilité : Confort visuel maximal, réduit la fatigue visuelle tout en conservant un contraste parfait avec les textes sombres.6. Luxury GoldHEX : #C5A059RGB : rgb(197, 160, 89)HSL : hsl(39°, 48%, 56%)Usage : Éléments de distinction (badges récompense, packaging, notes/avis, détails métalliques).Accessibilité : S'utilise idéalement sur fond sombre ou sous forme d'icônes et bordures.7. Warm GrayHEX : #8C857BRGB : rgb(140, 133, 123)HSL : hsl(35°, 6%, 52%)Usage : Textes d'aide, fil d'Ariane, labels de formulaires, icônes secondaires.Accessibilité : Conforme WCAG AA pour les textes secondaires sur fond Cream White.8. CharcoalHEX : #2C2C2CRGB : rgb(44, 44, 44)HSL : hsl(0°, 0%, 17%)Usage : Corps de texte principal, descriptions de produits, avis clients.Accessibilité : Conforme WCAG AAA (Contraste 12.5:1 sur fond Cream White).9. BlackHEX : #111111RGB : rgb(17, 17, 17)HSL : hsl(0°, 0%, 7%)Usage : Éléments de fort impact (Bannière d'annonce, boutons "Commander", Footer haut de gamme).Accessibilité : Contraste absolu (20:1+), conforme WCAG AAA.10. WhiteHEX : #FFFFFFRGB : rgb(255, 255, 255)HSL : hsl(0°, 0%, 100%)Usage : Cartes produit, champs de formulaires (inputs), fenêtres modales.Accessibilité : Fond neutre de référence.3.
